# OpenCode Advisor

Плагин OpenCode: отдельная модель-ревьюер читает каждый законченный шаг агента
и кладёт в его контекст короткий совет с уровнем важности. Совет приходит в чат
строкой `Advisor · concern: …`, журнал советов пишется в файл.

Уровни: `nit` — замечание, `concern` — стоит поправить, `blocker` — дальше идти
нельзя.

## Установка

Добавьте путь к этой папке в `opencode.json`:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["/mnt/f/_Project/Plugins/Opencode/opencode-advisor-extended"],
}
```

Конфигурация перечитывается без перезапуска. Если плагин не подхватился,
выполните `/reload` или перезапустите OpenCode.

## Настройка модели

Без полной пары provider/model ревьюер молчит, а в статусе стоит
`model-missing`. Это не ошибка: так экономится вызов модели.

```
/advisor model set <provider>/<model>
```

Пара пишется в `config.json` и переживает перезапуск. Остальные настройки — в
том же файле:

| Ключ                | По умолчанию | Что делает                                                  |
| ------------------- | ------------ | ----------------------------------------------------------- |
| `enabled`           | `true`       | Общий выключатель ревьюера                                  |
| `provider`, `model` | пусто        | Пара для вызова ревьюера                                    |
| `immuneTurns`       | `3`          | Сколько шагов пропускать после `concern`/`blocker`          |
| `maxDeltaMessages`  | `60`         | Сколько сообщений отдавать ревьюеру (`0` — без ограничения) |
| `noteMaxChars`      | `768`        | Предел длины совета                                         |
| `proseFallback`     | `false`      | Доставлять ответ без JSON как `nit`                         |

Плагин перечитывает `config.json` без перезапуска.

## Как совет попадает к агенту

`nit` кладётся в контекст агента и всплывает на следующем шаге. `concern` и
`blocker` дополнительно приходят отдельным сообщением, которое будит агента,
чтобы он поправился сразу.

## Команды

```
/advisor on | off | status
/advisor model set <provider>/<model>
/advisor model reset
```

- `on`/`off` — только текущая сессия, в памяти; после рестарта сессия снова
  включена.
- `status` — состояние, модель, счётчики вызовов и дропов, причина последнего
  пропуска, задержка.
- `model set` пишет в `config.json`; `model reset` очищает пару, после чего её
  нужно задать заново.

## Где лежат файлы

- `~/.config/opencode-advisor/config.json` — настройки.
- `~/.local/state/opencode-advisor/journal-<loc>.jsonl` — журнал советов, одна
  JSON-строка на запись. `<loc>` — первые 8 hex sha256 каталога проекта, поэтому
  worktree не смешиваются. Ротация при 1 МБ или 5 000 строк, старый файл
  переименовывается в `.1`.

Если плагин раньше стоял как расширение OpenChamber, при первом запуске конфиг
и журналы переносятся из `~/.config/openchamber-advisor` и
`~/.local/state/openchamber-advisor`. Существующие файлы не перезаписываются.

## Если что-то не работает

- **Советов нет, шаги идут** — ревьюер мог не найти, что сказать (`NO_ADVICE`),
  или ответ не разобрался. `/advisor status` покажет счётчики дропов: `empty` —
  модель промолчала, `unparsed` — ответ не JSON-кадр, `error` — вызов модели
  сорвался (после этого сессия молчит до `/advisor on` или правки конфига).
- **`model-missing`** — задайте provider и model командой
  `/advisor model set <provider>/<model>`.
- **`пропуск: gate`** — сессия ещё не набрала `immuneTurns` шагов после прошлого
  совета; это нормальное поведение.
- **`пропуск: foreign`** — сессия принадлежит другому каталогу; один сервер
  обслуживает несколько проектов, и чужой совет в этот контекст не попадает.

## Как отключить

- `/advisor off` — только текущая сессия, до рестарта.
- Полностью: уберите путь из `plugins` в `opencode.json` и, если нужно, удалите
  папки `~/.config/opencode-advisor` и `~/.local/state/opencode-advisor`.

## Разработка

```bash
npm install
npm run build   # plugin/index.js
npm test        # node --test
npm run lint
```

Собранный файл коммитится в git: загрузчик плагина берёт его, а не исходники.

- `src/plugin/` — плагин OpenCode: подписка на шаги, вызов ревьюера, доставка,
  журнал; `review.js` — один вызов на шаг, `prompts.js` — текст для ревьюера.
- `src/core/` — чистые модули: конфиг, дельта транскрипта, рамка ответа, лимиты,
  журнал, миграция старых каталогов.
