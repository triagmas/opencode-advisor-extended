# OpenChamber Advisor

Расширение OpenChamber: отдельная модель-ревьюер читает каждый законченный шаг
агента и кладёт в его контекст короткий совет с уровнем важности. Человеку
достаются журнал в правой панели, секция Work Status рядом с чатом и карточка
«Дальше» в конце ответа агента — с кнопкой, которая кладёт подсказку в поле
ввода.

Уровни: `nit` — замечание, `concern` — стоит поправить, `blocker` — дальше идти
нельзя.

## Установка

1. OpenChamber → **Settings → Extensions → Add**.
2. Укажите путь к этой папке:
   `/mnt/f/_Project/Plugins/Opencode/opencode-advisor-extended`.
3. Подтвердите разрешения:
   - файлы `~/.local/state/openchamber-advisor/**` — журнал и heartbeat;
   - файлы `~/.config/openchamber-advisor/**` — настройки;
   - строка «Add a plugin to OpenCode» — без неё совет не попадёт в контекст
     агента, а останется только журналом.
4. Если плагин не подхватился, перезапустите OpenCode.

После установки на правой рейке появляется иконка **Advisor**.

## Настройка модели

Откройте панель Advisor → вкладка **Настройки** → укажите `provider` и `model` →
**Сохранить**. То же самое из чата:

```
/advisor model set <provider>/<model>
```

Без полной пары provider/model ревьюер молчит, а в статусе стоит
`disabled-with-reason: model-missing`. Это не ошибка: так экономится вызов модели.

Остальные настройки:

| Ключ               | По умолчанию | Что делает                                                  |
| ------------------ | ------------ | ----------------------------------------------------------- |
| `enabled`          | `true`       | Общий выключатель ревьюера                                  |
| `immuneTurns`      | `3`          | Сколько шагов пропускать после `concern`/`blocker`          |
| `maxDeltaMessages` | `60`         | Сколько сообщений отдавать ревьюеру (`0` — без ограничения) |
| `noteMaxChars`     | `768`        | Предел длины совета                                         |
| `proseFallback`    | `false`      | Доставлять ответ без JSON как `nit`                         |

Плагин перечитывает `config.json` без перезапуска.

## Команды

```
/advisor on | off | status
/advisor model set <provider>/<model>
/advisor model reset
```

- `on`/`off` — только текущая сессия, в памяти; после рестарта сессия снова
  включена.
- `status` — состояние, модель, счётчики вызовов и дропов, последняя задержка.
- `model set` пишет в `config.json` и переживает рестарт; `model reset` очищает
  пару, после чего её нужно задать заново.

## Где лежат файлы

- `~/.config/openchamber-advisor/config.json` — настройки, пишет панель и
  `/advisor model set`.
- `~/.local/state/openchamber-advisor/journal-<loc>.jsonl` — журнал советов, одна
  JSON-строка на запись. `<loc>` — первые 8 hex sha256 каталога проекта, поэтому
  worktree не смешиваются. Ротация при 1 МБ или 5 000 строк, старый файл
  переименовывается в `.1`.
- `~/.local/state/openchamber-advisor/status-<loc>.json` — heartbeat: версия
  плагина, модель, счётчики, последняя активность. Перезапись при изменении и раз
  в 10 секунд.

## Если что-то не работает

- **«Плагин не запущен» / heartbeat `stale`** — последний сигнал старше 30 секунд.
  Проверьте, что OpenCode запущен, расширение включено, а проект открыт в той же
  локации. На удалённом сервере это ожидаемо: файлового моста к нему нет.
- **`disabled-with-reason: model-missing`** — задайте provider и model в панели
  или командой `/advisor model set`.
- **Журнал пуст, а шаги идут** — ревьюер мог не найти, что сказать (`NO_ADVICE`),
  или ответ не разобрался. Посмотрите счётчики дропов на вкладке **Статус**:
  `empty` — модель промолчала, `unparsed` — ответ не JSON-кадр, `error` — вызов
  модели сорвался (после этого сессия молчит до `/advisor on` или правки конфига).
- **Work Status показывает «Ревьюер выключен»** — включите его в настройках
  панели.

## Как отключить

- Панель Advisor → **Настройки** → выключите «Ревьюер включён».
- Или `/advisor off` — только текущая сессия, до рестарта.
- Полностью: удалите расширение в OpenChamber → Settings → Extensions и, если
  нужно, папки `~/.config/openchamber-advisor` и
  `~/.local/state/openchamber-advisor` вручную.

## Ручная проверка после установки

1. Установка по пути → иконка **Advisor** на рейке, диалог прав с двумя
   файловыми паттернами и строкой про плагин OpenCode.
2. `/advisor status` без модели → текст про `model-missing`.
3. Задать модель в панели → `/advisor status` показывает её, heartbeat `live`.
4. Шаг агента → в журнале запись, у агента виден совет (уровень выбирает
   ревьюер: `nit`, `concern` или `blocker`).
5. `concern`/`blocker` с `synthetic` + `steer` приходят в чат и будят агента;
   `nit` ждёт следующего шага в контексте.
6. Выключить ревьюера → новых записей нет, статус «выключен».
7. Work Status → последний совет и кнопка «в инпут».
8. Ответ агента заканчивается карточкой «Дальше»: текст подсказки, «В инпут»
   кладёт его в поле ввода, «Скрыть» убирает и не возвращает после перезагрузки.

## Разработка

```bash
npm install
npm run build   # panel/main.js, status/main.js, block/main.js, plugin/index.js
npm test        # node --test
```

Собранные файлы коммитятся в git: установка расширения по пути берёт их, а не
исходники.

- `src/plugin/` — плагин OpenCode: подписка на шаги, вызов ревьюера, доставка,
  журнал и heartbeat.
- `src/core/` — чистые модули: конфиг, дельта транскрипта, рамка ответа, лимиты,
  журнал, статус.
- `src/panel/` — страницы панели и Work Status.
- `src/block/` — карточка «Дальше»: UI-блок OpenChamber в конце ответа агента.
- `docs/superpowers/` — утверждённый дизайн и план реализации.
