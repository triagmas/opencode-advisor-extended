Реализуй плагин OpenChamber Advisor по готовым спецификации и плану.

**Каталог:** `/mnt/f/_Project/Plugins/Opencode/opencode-advisor-extended`

**Сначала прочитай целиком, до первой строки кода:**
1. `docs/superpowers/specs/2026-11-21-advisor-design.md` — что строим и почему.
2. `docs/superpowers/plans/2026-11-21-advisor-implementation.md` — 11 задач с тестами.

**Правила:**
- Работаем по плану, задачи по порядку, шаги отмечать `- [x]`.
- TDD: сначала падающий тест, потом код; `node --test test` перед каждым коммитом.
- Сборка: `npm run build` (esbuild). `plugin/index.js` — один файл без импортов из `node_modules`; `panel/main.js` и `status/main.js` — IIFE, коммитятся в git (git-установка расширения берёт собранные файлы).
- GitHub: репозиторий `triagmas/opencode-advisor-extended`, приватный, `gh` уже авторизован (`gh repo view` показывает, что его ещё нет — создаём в Task 1). После каждого коммита — `git push`.
- Секретов в репозиторий и в argv не класть; `~/.config/openchamber-advisor/*` и `~/.local/state/openchamber-advisor/*` — только пути в коде.
- Не менять утверждённый дизайн по ходу: нашёл дыру — остановись, опиши одной строкой, спроси.
- Стиль ответов — ADHD-режим из `~/.config/opencode/AGENTS.md`.

**Начинай с Task 1.** В конце каждой задачи: что сделано, что проверено командой и её выводом, что осталось.
